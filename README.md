# 🤖 GenAI Chatbot using Ollama + Streamlit

An AI-powered chatbot built using **Python, Streamlit, LangChain, and Ollama**. The chatbot supports multiple open-source Large Language Models (LLMs) such as **Mistral**, **Llama 3**, and **Gemma**.

## 🚀 Features

- 🤖 Multi-LLM Support (Mistral, Llama 3, Gemma)
- 🎨 Clean Streamlit Interface
- ⚡ Fast Local AI Inference using Ollama
- 🔄 Adjustable Temperature
- 💬 Real-time Question Answering
- 🔓 100% Open Source

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/gayathri031024-cmyk/Genaichatbot.git
```

Move into the project

```bash
cd Genaichatbot
```

Create Virtual Environment

```bash
python -m venv venv311
```

Activate

Windows

```bash
venv311\Scripts\activate
```

Install Packages

```bash
pip install -r requirements.txt
```

Run Ollama

```bash
ollama serve
```

Download Models

```bash
ollama pull mistral
ollama pull llama3
ollama pull gemma
```

Run Streamlit

```bash
streamlit run bot.py
```
